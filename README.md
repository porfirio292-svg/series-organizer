# Kodi Series File Organizer

Aplicação Android para organizar automaticamente nomes de episódios e legendas e permitir a renomeação manual de ficheiros.

## Versão 1.3
- Nome da aplicação: Kodi Series File Organizer.
- Renomeação manual de ficheiros MKV, MP4, AVI e SRT.
- Preservação da extensão original e da pasta de origem.
- Validação de nomes vazios e de ficheiros duplicados antes de renomear.
- Atualização da lista de ficheiros após a operação.
- Interface em português de Portugal quando o idioma do dispositivo é português (Portugal); inglês nos restantes casos.
- Organização automática por padrões S01E01, 1x01 e Season 1 Episode 01.
- Operação de renomeação automática executada em segundo plano, seguida de nova leitura e validação dos ficheiros.

## Compilação
O GitHub Actions compila o APK de depuração. O artefacto da versão 1.3 tem o nome `Kodi_Series_File_Organizer_v1.3.apk`.
